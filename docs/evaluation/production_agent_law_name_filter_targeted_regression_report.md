# Law-name metadata filter targeted regression

- 대상 모델: `gpt-5.6-sol`
- 대상 문항: 2024 공인중개사법령 및 중개실무 9, 21, 27, 37번
- 실험 경로: `production_agent_passthrough_law_name_filter_experiment`
- 변경 변수: evaluation-only `law_names` metadata filter 연결
- fallback 조건: filtered 결과가 0건일 때만 기존 unfiltered semantic search 수행
- 실제 fallback: 0건
- 변경하지 않은 항목: 운영 Prompt/Provider/Validator, exact lookup, top-k, threshold, corpus, Vector Store, Tool round 한도

## 결론

- 법률명 filter는 37번의 유사 법령 ranking 문제를 직접 해결했다.
- 21번도 관련 법령군 안에서 검색되어 정답으로 회복했다.
- 27번은 필요한 조문이 Top-K에 진입했지만 Tool-loop 종료 문제는 남았다.
- 9번은 법령군을 제한해도 정확한 시행규칙 제6조를 찾지 못해 exact article lookup 필요성이 유지된다.
- 이번 결과만 보면 다음 분리 실험 후보는 B. exact law/article lookup이며, 9·27번이 주요 targeted 문항이다.
