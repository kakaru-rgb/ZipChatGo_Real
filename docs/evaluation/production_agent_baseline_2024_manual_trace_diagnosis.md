# 2024 공인중개사 운영 Agent baseline 수동 Retrieval/Reasoning 진단

- 기준 결과: `공인중개사_운영Agent_passthrough_baseline_2024_40_reanalyzed_v2.csv`
- 분석 대상: `retrieval_vs_reasoning_review_required` 15문항
- 분석 방식: 저장된 `법률ToolTrace`의 `model_query`, Top-K 결과, score, 원문 본문과 저장된 Agent 응답만 사후 대조

## 판정 기준

- `reasoning_failure`: 정답 판별에 필요한 조문과 핵심 문장이 Top-K 본문에 있었지만 Agent가 반대로 읽거나 적용함.
- `retrieval_failure`: 관련 법령명만이 아니라 정답 판별에 필요한 실제 조문 또는 핵심 문장이 Top-K에 없음.
- `retrieval_ranking_failure`: 필요한 근거도 검색됐지만 혼동하기 쉬운 유사 법령이 더 높은 순위에 배치되어 오판에 영향을 준 정황이 뚜렷함.
- `query_generation_failure`: Agent가 만든 query가 지나치게 넓거나 핵심 쟁점을 빠뜨려 필요한 조문을 검색하기 어려웠음.
- `mixed_retrieval_reasoning`: 일부 핵심 근거는 있었으나 완전하지 않았고, Agent의 잘못된 독해도 동시에 확인됨.
