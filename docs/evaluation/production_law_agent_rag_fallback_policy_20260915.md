# Production 법률 Agent RAG fallback 정책 기록

작성일: 2026-09-15

## 작업 목적

실제 사용자의 부동산 법률 질문에 공식 법령 검색 결과를 우선 활용하면서, 검색이 불완전하거나 실패해도 Luna의 일반 법률 지식으로 유용한 설명을 제공하도록 production 동작 원칙을 조정했다. 공인중개사 시험 정답률 개선을 위한 문제별 규칙은 추가하지 않았다.

설계 근거로 확인된 동일 2024년 40문항 비교는 Luna Direct **72.5% (29/40)**, Agent+RAG strict **60.0% (24/40)**, 정상 답변에 대한 conditional accuracy **82.8%**였다. 이 비교는 RAG의 공식 근거 제공 능력을 유지하면서 검색 실패가 답변 실패로 이어지는 경로를 완화할 필요가 있음을 보여준다. 이번 정책 변경 후의 성능 수치는 아니다.

## 변경 파일

| 파일 | 변경 내용 |
|---|---|
| `ai-server/app/prompts.py` | 법률 RAG 우선 사용 조건, 충분·부분·실패 검색별 답변 방식, 일반 지식의 출처 구분, 최신 자료 요청과 허위 출처 금지, 반복 검색 중단 지침을 추가했다. |
| `ai-server/app/providers/openai_provider.py` | 법률 Tool 사용 지침과 검색 후 안내를 조정했다. 검색 0건 또는 조문 번호를 인용하지 않는 일반 설명을 자동 거절하던 경로를 완화했다. 검색되지 않은 조문 번호를 인용한 답변에 대한 기존 차단은 유지했다. |
| `ai-server/app/tools/real_estate_law.py` | 검색 결과의 `grounding_notice`에 일반 지식 보완은 가능하지만 검색된 공식 근거로 오인시키거나 확인되지 않은 조문을 인용하지 말라는 지침을 반영했다. |
| `ai-server/tests/test_openai_provider.py` | 검색 0건 fallback, 부분 검색에서의 일반 설명, 검색되지 않은 조문 인용 차단을 검증했다. |
| `ai-server/tests/test_real_estate_law_tool.py` | 변경된 법률 검색 결과 안내문의 기대값을 갱신했다. |

## 최종 법률 답변 정책

- **RAG 성공:** 질문에 충분한 공식 조문이 검색되면 실제 결과의 법령명·조문·시행일과 본문을 적극 활용한다. 근거가 충분한 부분에 불필요한 caveat를 반복하지 않는다.
- **RAG 부분 성공:** 검색으로 직접 확인된 범위를 근거로 설명하고, 부족한 세부 내용은 Luna의 일반 법률 지식으로 보완할 수 있다. 보완 내용까지 검색 조문이 직접 뒷받침하는 것처럼 표현하지 않는다.
- **RAG 실패:** 검색 0건을 답변 실패로 취급하지 않는다. 일반적인 법률 설명을 제공할 수 있으며, 현재 연결된 공식 검색에서 직접 확인하지 못했다는 점과 구체적 적용 전 최신 법령·판례 확인 필요성을 알린다. 단, 검색되지 않은 조문 번호를 인용하는 답변은 기존 Provider 검사에서 차단한다.
- **Source-sensitive 질문:** 최신 판례·행정해석·개정 내용·특정 공식 공고를 요청받았으나 해당 자료를 확인하지 못했다면 그 사실을 명시한다. 이후 일반적인 법리는 설명할 수 있지만, 확인하지 않은 최신 자료가 실제로 판단한 것처럼 말하지 않는다.
- **Fabricated source 방지:** 공식 citation은 실제 검색된 근거에만 연결한다. 확인하지 않은 법령·조문·판례번호·시행일을 만들어 제시하거나, 다른 법령과 조문을 잘못 짝짓거나, 검색된 조문을 검색 밖의 별도 주장에 대한 근거처럼 사용하지 않도록 지시한다. 기존 Provider의 조문 번호 검사도 유지한다. 이 원칙은 Prompt와 기존 검사를 통한 동작 지침이며 모든 주장에 대한 별도 자동 검증기를 추가한 것은 아니다.

정확한 조문, 기간·기한·금액·비율, 권리 발생 요건, 신고·허가, 처벌·과태료, 개정 가능성이 큰 내용 또는 공식 근거 요청에는 법률 Tool을 우선 고려한다. 간단한 일반 법률 설명에 Tool 호출을 강제하지 않는다. 충분한 근거를 확보했거나 반복 검색에서 새롭고 의미 있는 근거가 나오지 않으면 검색을 멈추고 답변한다.

## 경계와 검증

- **C2.3은 evaluation-only** citation/provenance 진단용이다. Production 사용자 답변을 자동 차단하는 hard gate로 연결하지 않았다.
- **Tool-loop round 제한 자체는 변경하지 않았다.** 새로운 반복 검색 중단 엔진이나 Validator도 추가하지 않았다.
- 지도·매물·역 검색·법률 Tool·Agent API 관련 단위 및 regression 테스트 **37개가 통과**했다. 테스트 과정에서 6개의 기존 Pydantic 경고가 출력됐다.
- 이 정책 변경 후 **2024년 40문항 live API regression은 다시 실행하지 않았고, 2025년 문제도 실행하지 않았다.** 따라서 새 정책의 live 성능은 아직 측정하지 않았다.
- 기존 지도·매물·POI·관심매물 기능과 `.env` 설정은 이번 정책 변경에서 수정하지 않았다.
